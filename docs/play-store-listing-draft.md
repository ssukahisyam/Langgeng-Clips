# Play Store Listing Draft

## Short Description

AI video clipper for turning long videos into short-form vertical clips.

## Full Description

Langgeng Clip helps creators turn long-form videos into short-form 9:16 clips. Import a video, select or generate clip ranges, apply templates, edit captions, add watermark styling, and export mobile-ready clips.

Key features planned for V1:

- Manual timeline clipping.
- AI-assisted transcript and highlight foundations.
- Caption editor with live preview.
- Template presets for podcast, gaming, talking head, and tutorial content.
- Watermark controls.
- Export history and sharing.

Bring your own Groq API key for AI-powered features.
