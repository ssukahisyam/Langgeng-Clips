# Code Of Conduct

## Our Pledge

We commit to a respectful, focused, and constructive project environment.

## Expected Behavior

- Use welcoming and inclusive language.
- Give and receive feedback constructively.
- Respect differing viewpoints and constraints.
- Prioritize user safety, privacy, and product quality.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Publishing private information without permission.
- Sharing secrets, API keys, keystores, or user data.
- Disruptive behavior that blocks project progress.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or restrict access when behavior violates this code.
